仓库

    管理员可用「直通新建」；普通用户的建库申请需要管理员在审批台处理。

    成员

        owner 可管理全部成员；maintainer 只能增删 writer / reader。改动立刻生效： 被移除或降为只读的成员，手上的提交会话会同时作废。

        空间

        选择仓库后加载

          「可释放」只算被该目录独占的内容（含只属于它的历史版本），所以可能大于 「当前」——后者是 HEAD 里这些文件的字节数。清理前请先用「预估所选」确认。

          回收站

            撤销会把内容恢复成一次新提交，并让 GC 不再跳过这些路径。内容若已被物理回收， 撤销会直接失败——历史不会凭空长回来。

            保留策略

              keep_months / 字节上限 / 天数 三者任一被违反就会成为清理候选；目录按名称倒序当作 「从新到旧」。「仅预览」的策略即使点「执行清理」也会被服务端拒绝。
